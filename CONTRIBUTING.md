# Contributing

Pauselith is an AI-directed software-development project. Implementation was generated by coding agents, primarily Codex, under William Campos's direction of requirements, priorities and decisions. Its original code is MIT licensed; third-party terms are independent. Public source publication is authorized; public binary downloads remain excluded. Use Windows x64, PowerShell and the pinned toolchain in docs/BUILD.md.

Work on focused branches with synthetic fixtures. Do not commit recordings, settings, credentials, jobs, logs, caches or binaries. Run Fast; run Full when media/worker/interface behavior is affected. Report reproduction steps and validation limits. Never refresh frozen detector/profile hashes merely to pass tests; changed behavior needs separate evidence/review.

Preserve authoritative settings snapshots and confirmed worker states. Cancellation owns only its process tree; outputs preserve originals/valid earlier work. Storage/packaging changes need install/update/uninstall tests. Dependency changes require hashes, licensing review and affected tests. Review/redact paths before posting logs.

README contains commands; docs/RELEASING.md describes the source-only publication boundary. Inspect GitHub Actions for actual CI results rather than inferring them from local validation.
